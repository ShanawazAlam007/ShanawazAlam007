## ⚡ Executive Dossier

> 🔐 *"Security is not a product, but a continuous process of verification, attack-surface minimization, and defensive resilience."*

I am a **Cybersecurity Specialist & Systems Engineer** with a deep passion for offensive security, low-level network packet analysis, and scalable secure cloud architecture. 

- 🛡️ **Vulnerability Research & Red Teaming**: Hands-on penetration testing across web applications, network infrastructure, and APIs following structured methodologies.
- ⚡ **High-Performance Systems & NIDS**: Engineering wire-speed network intrusion detection daemons in **C++** combined with asynchronous **Machine Learning** classification models in **Python**.
- ☁️ **Cloud & Secure Infrastructure**: Designing resilient cloud architectures on **Microsoft Azure**, integrating containerized Docker stacks, PostgreSQL, Nginx, and zero-trust identity flows.
- 🏁 **Capture The Flag (CTF)**: Creator of production CTF competition portals and active security challenge solver.
- 🎓 **Education**: Computer Science Engineering at KIIT University.
